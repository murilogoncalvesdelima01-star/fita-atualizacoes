# Fita — atualizações

Aqui ficam as versões prontas do **Fita** (animador de partes).

**Primeira vez:** baixe o [Instalar-Fita.exe](https://github.com/murilogoncalvesdelima01-star/fita-atualizacoes/releases/download/instalador/Instalar-Fita.exe),
abra e clique em *Instalar*. Ele baixa a versão mais nova e cria o atalho na Área de Trabalho.
(Se o Windows avisar "O Windows protegeu o computador": *Mais informações* > *Executar assim mesmo*.)

**Depois:** o próprio Fita avisa quando sai versão nova (ou *Ajudar > Procurar atualização*).
